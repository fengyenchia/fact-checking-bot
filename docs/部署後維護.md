# Threads 查證 Demo｜部署後維護

## 更新網站

- 本機修改與預覽：`pnpm dev`。
- 修改完成後執行 `pnpm test`、`pnpm lint` 及 `pnpm build`；本機 Turbopack 若無法編譯，可用 `pnpm exec next build --webpack`。
- 將程式推送到 Vercel 綁定的分支，確認 **Deployments** 顯示部署成功，再開正式網址檢查。
- 官網資料、TWNIC 通報清單、字型或劇本有改動時，需要重新部署；官網來源見 [官網資料](官網網址與來源.md)。
- 更換測試情境時，修改 [劇本原文](../data/scenarios/ticket.ts) 並更新 `scenarioVersion`，避免沿用舊進度。

## 必要設定

- 本機設定放在 `.env.local`；正式站設定在 Vercel **Settings → Environment Variables**。
- 修改本機設定後重新啟動 `pnpm dev`；修改 Vercel 設定後，到 **Deployments → Redeploy** 讓設定生效。

| 變數 | 用途 |
| --- | --- |
| `DATABASE_URL` | Neon 資料庫連線。 |
| `OPENAI_API_KEY` | AI 回覆、案例整理與檢索。 |
| `ADMIN_PASSWORD` | 後台登入密碼。 |
| `ADMIN_SESSION_SECRET` | 後台登入狀態的簽署金鑰，至少 32 字元。 |
| `OPENAI_MODEL` | 選填；更換 AI 回覆及分析模型。 |

## 後台資料維護

| 入口 | 操作 |
| --- | --- |
| `/admin/cases` | 新增或編輯案例；要重選首頁卡片時，按「更新首頁案例卡」。 |
| `/admin/accounts` | 維護可疑 Threads 帳號與顯示人數；查詢不會自動累加人數。 |
| `/admin` | 依場次查看受測者輸入、選取訊息與工具回覆。 |

- 核對案例原文時，依發布日期與縣市回到 [165 打詐儀錶板](https://165dashboard.tw/city-case-summary) 查找。
- 在 Neon 直接修改資料後，重新整理後台；筆數不同時，確認分支、資料庫與網站的 `DATABASE_URL` 是否一致。
- 更新程式不會自動刪除既有受測紀錄。

## 更新後快速檢查

- [ ] 四個功能能送出、返回與重試；網址四種結果、帳號命中與未命中的結果正確。[功能流程與結果](../README.md#四個功能的判斷流程與結果)
- [ ] 對話評估只依勾選內容判斷；快速對話可多輪追問，回答與工具按鈕符合問題。
- [ ] 案例卡與內容相關、最多三張，沒有適合案例時省略；首頁已更新為本次測試使用的案例。
- [ ] 用實機確認捲動、底部導覽、鍵盤、安全區和橫向畫面；一般問候與可疑付款要求的 AI 判讀需人工複核。
- [ ] 同一天重整保留進度、隔天建立新場次；後台可找到對應的輸入與回覆。
- [ ] 連線或 AI 失敗、等候超過 45 秒時，會停止載入並保留輸入；重試不重複建立紀錄。
- [ ] 定期確認 OpenAI 剩餘額度、到期日及用量通知。
