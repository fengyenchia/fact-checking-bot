# 響應式檢查

- 檢查日期：2026-11-22。
- 環境：本機開發頁面的瀏覽器 viewport 測試，使用實際三張首頁案例。

## 已修正

- 案例卡內的 `sr-only` 文字為絕對定位，原本沒有以卡片作為定位基準，會超出橫向捲動區並撐寬頁面。
- 在 `CaseCard` 連結加入 `relative`，讓隱藏文字留在卡片內；440 px 視窗的頁面捲動寬度由 551 px 回到 440 px。
- Widget 在 852×393 橫向畫面原本只剩約 201 px 高，選單捲動區高度為零。
- 高度 512 px 以下時，Widget 改用可用高度、縮小選單封面及標題上方間距；852×393 的選單捲動區約為 105 px，可操作四項工具與如何使用。
- 直向手機、平板與一般桌面維持原本的版面與字級。

## 已完成檢查

- **首頁八種尺寸**：320×568、360×800、375×667、393×852、440×956、768×1024、1280×800、852×393。
- **首頁結果**：頁面捲動寬度均未超出視窗；五個導覽圖示存在，底部導覽貼齊視窗下緣。
- **聊天室六種尺寸**：320×568、393×852、440×956、768×1024、1280×800、852×393；輸入框下緣與導覽列上緣對齊。
- **Widget 五種尺寸**：320×568、440×956、768×1024、1280×800、852×393；選單均保留可捲動高度。
- **橫向操作**：選單可捲動到如何使用，說明框可捲動、回首頁可點擊，連結查證可進入。

## 實機仍需複核

- 真實手機鍵盤展開後的輸入及捲動。
